# Insurance Claim Prediction System

## Overview
This project is a full-stack AI-based system designed to predict insurance claim
approval and claim severity based on vehicle damage estimation. The system uses
deep learning models to analyze vehicle damage images and supports decision-making
for insurance companies.

---

## Features
- Vehicle damage analysis using deep learning
- Insurance claim approval prediction
- Confidence-based output for claims
- Full-stack architecture (Frontend + Backend)
- Modular and scalable design

---

## Tech Stack
### Backend
- Python
- Flask / FastAPI
- PyTorch
- OpenCV
- NumPy, Pandas

### Frontend
- React.js
